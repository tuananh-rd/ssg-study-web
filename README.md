# Web ôn thi cuối kỳ: SSG105, DAP391m, AIL303m, CPV301

Web ôn thi bốn môn (lý thuyết, luyện tập, bộ đề, thi thử, thi đấu trực tuyến, chatbot, chat chung). Chạy trên Cloudflare Pages + D1. Đề thi bằng tiếng Anh, bài giảng bằng tiếng Việt.

- Giao diện dùng chung: `src/`. Máy chủ (API): `web/functions/`. Trang chủ: `web/public/`.
- Cấu trúc, cách build, cách deploy và việc còn dang dở: xem [HANDOFF.md](HANDOFF.md).
- Dữ liệu học liệu có nguồn từ slide và tài liệu môn học; chỉ dùng để học cá nhân.
