# Data Analysis with Python

## Nhập và xuất Dữ liệu (Importing Datasets)
Trước khi phân tích, cần hiểu rõ vấn đề cần giải quyết và bản chất của bộ dữ liệu (số lượng biến, kiểu dữ liệu của từng thuộc tính)
- 
### Các thư viện Python cho Khoa học Dữ liệu (Python Packages for Data Science)
- Thư viện tính toán khoa học: Pandas (Cấu trúc dữ liệu và công cụ phân tích), NumPy (Mảng và ma trận đa chiều), SciPy (Các hàm toán học và thống kê).
- Thư viện trực quan hóa dữ liệu: Matplotlib (Đồ thị cơ bản), Seaborn (Trực quan hóa thống kê nâng cao, biểu đồ heatmap).
- Thư viện thuật toán Máy học: Scikit-learn (Xây dựng mô hình, tiền xử lý), Statsmodels (Khám phá dữ liệu, ước lượng mô hình thống kê).
- 
### Nhập và xuất dữ liệu (Importing and Exporting Data in Python)
Dữ liệu thường được lưu trữ dưới nhiều định dạng khác nhau (.csv, .json, .xlsx, .sql). Pandas cung cấp các hàm dựng sẵn để đọc và ghi dữ liệu cực kỳ tiện lợi.
import pandas as pd
# Đọc file CSV
df = pd.read_csv("data.csv")
# Xem 5 dòng đầu tiên
print(df.head())
# Xuất dữ liệu ra file CSV
df.to_csv("cleaned_data.csv", index=False)

## Làm sạch và tiền xử lý dữ liệu (Data Wrangling)

### Xử lý giá trị bị thiếu (Dealing with Missing Values)
Dữ liệu thực tế thường chứa các ô trống (NaN/Null). Có thể loại bỏ hoặc thay thế các giá trị này.
# Xóa các dòng có giá trị bị thiếu ở cột 'price'
df.dropna(subset=['price'], axis=0, inplace=True)
# Thay thế giá trị thiếu bằng giá trị trung bình (Mean Imputation)
mean_val = df['normalized-losses'].mean()
df['normalized-losses'].fillna(mean_val, inplace=True)

### Định dạng dữ liệu (Data Formatting)
Đảm bảo dữ liệu ở đúng kiểu định dạng. Ví dụ: đổi biến từ kiểu chuỗi (string) sang số thực (float).
df['price'] = df['price'].astype('float')
 | 
- 
### Chuẩn hóa dữ liệu (Data Normalization)
Đưa dữ liệu về cùng một thang đo để thuật toán học máy hoạt động hiệu quả hơn. Các phương pháp phổ biến:
Phương pháp
 | Công thức / Đoạn mã Python
 | 
Simple Feature Scaling
 | df['length'] = df['length'] / df['length'].max()
 | 
Min-Max Normalization
 | df['length'] = (df['length'] - df['length'].min()) / (df['length'].max() - df['length'].min())
 | 
Z-score (Chuẩn hóa chuẩn)
 | df['length'] = (df['length'] - df['length'].mean()) / df['length'].std()
 |

### Chia khoảng (Binning)
Phân nhóm các giá trị liên tục thành các khoảng (categorical bins) để phân tích dễ hơn (ví dụ: gộp giá tiền thành Thấp, Trung bình, Cao).
import numpy as np
bins = np.linspace(min(df['price']), max(df['price']), 4)
group_names = ['Low', 'Medium', 'High']
df['price-binned'] = pd.cut(df['price'], bins, labels=group_names, include_lowest=True)

dummy_var = pd.get_dummies(df['fuel-type'])
df = pd.concat([df, dummy_var], axis=1)

df_test = df[['drive-wheels', 'body-style', 'price']]
df_grp = df_test.groupby(['drive-wheels', 'body-style'], as_index=False).mean()

### Tương quan (Correlation)
Biểu diễn mối quan hệ phụ thuộc tuyến tính giữa các biến số với nhau. Chi tiết trong Ma trận tương quan:
- Đường chéo (Diagonal Line): Một ma trận tương quan sẽ có đường chéo màu đỏ đậm (khi dùng Heatmap), cho thấy rằng mọi biến luôn có hệ số tương quan hoàn hảo là 1 với chính nó.
- Tương quan dương (Positive Correlation): Khi kích thước động cơ (engine-size) tăng thì price (giá xe) cũng tăng. Suy ra có mối tương quan tuyến tính thuận.
- Tương quan âm (Negative Correlation): Khi số dặm đi được trên một gallon cao tốc (highway-mpg) tăng thì price có xu hướng giảm. Đây là tương quan tuyến tính nghịch.
import seaborn as sns
import matplotlib.pyplot as plt
# Tính Pearson Correlation
correlation_matrix = df.corr()
# Trực quan hóa Heatmap
sns.heatmap(correlation_matrix, annot=True, cmap='RdBu')
plt.show()
# Biểu đồ phân tán (Scatter Plot) với đường hồi quy
sns.regplot(x="engine-size", y="price", data=df)
plt.show()

## Phát triển Mô hình (Model Development)
- 
### Hồi quy đa thức và Pipelines (Polynomial Regression and Pipelines)
Khi mô hình tuyến tính đơn giản không khớp tốt với dữ liệu (không bắt được các đường cong trong dữ liệu), ta dùng Hồi quy Đa thức. Việc sử dụng Pipeline giúp đơn giản hóa quá trình biến đổi dữ liệu.
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, PolynomialFeatures
from sklearn.linear_model import LinearRegression
# Xây dựng Pipeline: Chuẩn hóa -> Biến đổi Đa thức -> Mô hình Hồi quy Tuyến tính
Input = [('scale', StandardScaler()), 
         ('polynomial', PolynomialFeatures(degree=2)), 
         ('model', LinearRegression())]
pipe = Pipeline(Input)
pipe.fit(X, y)
y_pipe_predict = pipe.predict(X)

### Các thước đo đánh giá In-Sample (Measures for In-Sample Evaluation)
- R-squared (

- Mean Squared Error (MSE): Giá trị trung bình của bình phương các sai số. MSE càng nhỏ thì mô hình càng chính xác.

## Đánh giá và tinh chỉnh mô hình (Model evaluation and refinement)
- 
### Overfitting, Underfitting và chọn Mô hình
Mô hình bị quá khớp (Overfitting) sẽ bắt "nhiễu" (noise) của dữ liệu huấn luyện, dẫn đến kết quả kém trên dữ liệu mới. Ngược lại, Underfitting xảy ra khi mô hình quá đơn giản. Cần chia nhỏ dữ liệu thành Training/Testing để đánh giá hiệu suất.
from sklearn.model_selection import train_test_split
x_train, x_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

- 
### Hồi quy Ridge (Ridge Regression)
Sử dụng khi có hiện tượng đa cộng tuyến hoặc khi mô hình đa thức bị overfitting. Tham số `alpha` kiểm soát mức độ phạt (penalty) đối với các hệ số.
from sklearn.linear_model import Ridge
RigeModel = Ridge(alpha=0.1)
RigeModel.fit(x_train, y_train)
yhat = RigeModel.predict(x_test)
 |

### Grid Search (Tìm kiếm lưới siêu tham số)
Grid Search là phương pháp vô cùng hiệu quả với ưu điểm là giúp chúng ta kiểm tra nhanh chóng nhiều siêu tham số (hyperparameters) khác nhau để tìm ra mô hình tối ưu. Mặc định phương pháp sử dụng điểm R-squared làm scoring.
from sklearn.model_selection import GridSearchCV
# Khởi tạo một Dictionary các siêu tham số (dictionary of parameter values)
parameters = [{'alpha': [0.001, 0.1, 1, 10, 100, 1000]}]
# Tạo object mô hình Ridge Regression
RR = Ridge()
# Khởi tạo GridSearchCV (Truyền vào object mô hình, tham số, số K-folds)
Grid1 = GridSearchCV(RR, parameters, cv=4)
Grid1.fit(X, y)
# Lấy ra các giá trị tối ưu thông qua thuộc tính best_estimator_
BestRR = Grid1.best_estimator_
# Lấy thông tin về điểm validation trung bình thông qua thuộc tính cv_results_
cv_res = Grid1.cv_results_
print(BestRR.score(x_test, y_test))
 |

Chương này giới thiệu các công cụ cơ bản như Matplotlib, các biểu đồ lạ lạ (ví dụ: Waffle Chart, Word Cloud, bản đồ địa lý Folium) cho đến cách xây dựng các bảng điều khiển (Dashboards) tương tác bằng Plotly và Dash.

## Overview
Trực quan hóa dữ liệu giúp chuyển đổi dữ liệu thô thành các biểu diễn đồ họa để dễ dàng phát hiện xu hướng, mẫu (patterns) và ngoại lai. Matplotlib là thư viện cốt lõi trong Python cho việc này, với hai cách tiếp cận chính: Scripting layer (pyplot) và Artist layer (Object-oriented). Thật ra thằng Seaborn cũng được ưu dùng tại nó vẽ biểu đồ đẹp hơn với có mấy cái tùy chỉnh và tính năng Matplotlib không có.

## Xây dựng Dashboards với Plotly và Dash
Dash là một framework mã nguồn mở của Python chuyên để xây dựng các ứng dụng web phân tích dữ liệu (Dashboards) mà không cần dùng đến JavaScript hay HTML thuần. Dash cấu thành từ:
- Dash HTML Components (dash.html): Cung cấp các thẻ HTML để xây dựng giao diện (Div, H1, P, v.v.).
- Dash Core Components (dash.dcc): Cung cấp các công cụ tương tác như Dropdown, Slider, và Graph (sử dụng biểu đồ Plotly).
- 
### Tạo Dashboard tương tác (Make Dashboards interactive)
Sự tương tác của Dash được điều khiển bởi Callback (hàm phản hồi). Decorator @app.callback kết nối Input (những gì người dùng thao tác, ví dụ chọn dropdown) với Output (biểu đồ hoặc văn bản cần được cập nhật tự động).
import dash
from dash import dcc, html
from dash.dependencies import Input, Output
import plotly.express as px
import pandas as pd
# Khởi tạo dữ liệu
df = pd.DataFrame({
    "Fruit": ["Apples", "Oranges", "Bananas", "Apples", "Oranges", "Bananas"],
    "Amount": [4, 1, 2, 2, 4, 5],
    "City": ["SF", "SF", "SF", "Montreal", "Montreal", "Montreal"]
})
app = dash.Dash(__name__)
# Xây dựng bố cục giao diện
app.layout = html.Div([

### Setup server to provide REST API

from flask import Flask, jsonify, request
import ibm_db
app = Flask(__name__)
# Cấu hình chuỗi kết nối thông tin xác thực lấy từ Db2 Console
dsn_driver = "{IBM DB2 ODBC DRIVER}"
dsn_database = "BLUDB"
dsn_hostname = "your-hostname.databases.appdomain.cloud"
dsn_port = "32733"
dsn_protocol = "TCPIP"
dsn_uid = "your_username"
dsn_pwd = "your_password"
dsn_security = "SSL"
dsn = (
    f"DRIVER={dsn_driver};"
    f"DATABASE={dsn_database};"
    f"HOSTNAME={dsn_hostname};"
    f"PORT={dsn_port};"
    f"PROTOCOL={dsn_protocol};"
    f"UID={dsn_uid};"
    f"PWD={dsn_pwd};"
    f"SECURITY={dsn_security};"
)
@app.route('/api/products', methods=['GET'])
def get_products():
    try:
        # Khởi tạo kết nối tới thực thể Db2
        conn = ibm_db.connect(dsn, "", "")
        sql = "SELECT * FROM MY_SCHEMA.PRODUCTS"
        stmt = ibm_db.exec_immediate(conn, sql)
        products_list = []

            products_list.append(row)
            row = ibm_db.fetch_assoc(stmt)
        ibm_db.close(conn)

### Phân tích bãi phóng không gian địa lý với Folium
Sử dụng thư viện Folium để ánh xạ các tọa độ bãi phóng (Launch Sites) của SpaceX lên bản đồ thực tế. Đồng thời áp dụng công thức toán học Haversine để tính toán khoảng cách từ vị trí bãi phóng đến các thực thể hạ tầng quan trọng xung quanh như đường bờ biển (coastlines), đường cao tốc (highways), và các trung tâm đô thị gần nhất để tìm ra mối tương quan an toàn bệ phóng.
import folium
from math import sin, cos, sqrt, atan2, radians
def calculate_distance(lat1, lon1, lat2, lon2):
    # Công thức toán học Haversine tính khoảng cách giữa hai tọa độ địa lý
    R = 6373.0 # Bán kính Trái Đất tính theo km
    lat1, lon1, lat2, lon2 = map(radians, [lat1, lon1, lat2, lon2])
    dlon = lon2 - lon1
    dlat = lat2 - lat1
    a = sin(dlat / 2)**2 + cos(lat1) * cos(lat2) * sin(dlon / 2)**2
    c = 2 * atan2(sqrt(a), sqrt(1 - a))
    return R * c

### Phát triển ứng dụng Dashboard với Plotly Dash
Xây dựng kiến trúc Dashboard động để phân tích hiệu suất phóng tên lửa thời gian thực qua 4 nhiệm vụ (Tasks) cấu trúc cốt lõi:
- TASK 1: Thêm một Drop-down Input component để người dùng lựa chọn giữa việc xem toàn bộ các bãi phóng (All Sites) hoặc chọn từng bãi phóng cụ thể.
- TASK 2: Thiết lập hàm callback render biểu đồ tròn (Success Pie Chart) phản ánh tỷ lệ phần trăm số lần phóng thành công và thất bại tương ứng với bãi phóng được chọn.
- TASK 3: Thêm cấu trúc thanh trượt Range Slider cho phép chọn bộ lọc khoảng khối lượng tải trọng (Payload Range) từ 0 kg đến 10,000 kg.
- TASK 4: Thiết lập hàm callback kết nối đầu ra hiển thị biểu đồ phân tán (Scatter Plot) thể hiện mối quan hệ tuyến tính giữa Payload và kết quả Class, ánh xạ màu sắc theo phiên bản lõi tên lửa (Booster Version).

from dash.dependencies import Input, Output

                 ], value='ALL', placeholder="Select a Launch Site here", searchable=True),
    html.Br(),
    html.Div(dcc.Graph(id='success-pie-chart')),
    html.Br(),
    html.P("Payload range (Kg):"),
    # TASK 3: Thành phần chọn khoảng khối lượng Range Slider
    dcc.RangeSlider(id='payload-slider', min=0, max=10000, step=1000,

### Thử nghiệm training và quét hyperparameters với GridSearchCV
Hệ thống tiến hành phân tách tập dữ liệu thành tập huấn luyện (Train set) và tập kiểm thử độc lập (Test set). Sau đó, thực hiện việc tìm kiếm tối ưu trên không gian tham số của 4 thuật toán phân loại kinh điển bao gồm: Logistic Regression, Support Vector Machine (SVM), Decision Tree Classifier, và K-Nearest Neighbors (KNN).
Thường các phần quét siêu tham số này sẽ khá lâu nhá
Thuật toán Phân loại
 | Không gian Siêu tham số Quét (Hyperparameters Grid)
 | Mục tiêu Tối ưu hóa Hệ thống
 | 
Logistic Regression
 | Hệ số phạt C: [0.01, 0.1, 1, 10], Hàm phạt penalty: ['l1', 'l2']
 | Tối ưu hóa ranh giới phân tách xác suất tuyến tính.
 | 
Support Vector Machine
 | Hệ số C, Hàm nhân kernel: ['linear', 'rbf', 'poly', 'sigmoid']
 | Tìm kiếm siêu phẳng có biên độ khoảng cách (margin) lớn nhất.
 | 
Decision Tree
 | Tiêu chí criterion: ['gini', 'entropy'], Độ sâu tối đa max_depth
 | Tách nhóm dữ liệu dựa trên mức độ thuần khiết của thông tin.
 | 
K-Nearest Neighbors
 | Số lượng láng giềng n_neighbors, Thuật toán tìm kiếm n_neighbors
